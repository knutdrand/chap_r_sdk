# Create optparse parser for predict subcommand

Create optparse parser for predict subcommand

## Usage

``` r
make_predict_parser(
  default_config_path = "config.yml",
  default_model_path = "model.rds"
)
```

## Arguments

- default_config_path:

  Default config file path

- default_model_path:

  Default model input path

## Value

An OptionParser object
