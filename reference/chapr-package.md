# chapr: Chap R SDK for Building Disease Forecasting Models

Provides convenience functionality for developing Chap-compatible models
and integrating existing models with the Chap (Climate Health Analytics
Platform) system. Includes utilities for creating command line
interfaces, model validation, spatio-temporal data transformations, and
configuration schema management.
