# Create optparse parser for train subcommand

Create optparse parser for train subcommand

## Usage

``` r
make_train_parser(
  default_config_path = "config.yml",
  default_model_path = "model.rds"
)
```

## Arguments

- default_config_path:

  Default config file path

- default_model_path:

  Default model output path

## Value

An OptionParser object
